MasterPortfolio (macOS)
=======================

흩어진 과제·보고서·발표자료·코드에서 이력서·포트폴리오에 쓸 경험을 찾아 정리하는 프로그램입니다.
분석은 이 Mac에 설치된 Claude Code(내 구독)로 하고, 자료는 내 Mac 밖 다른 서버로 보내지 않습니다.
(가려진 텍스트만 내가 쓰는 Claude로 전송됩니다)

준비
- Claude Code 설치와 로그인: https://claude.com/claude-code (설치 후 터미널에서 claude 를 한 번 실행해 로그인)
- 인터넷 연결 (처음 분석할 때 연결 도구를 자동으로 받습니다)
- Node.js 설치는 필요 없습니다(프로그램에 포함).

실행
1. 압축을 푼 MasterPortfolio 폴더를 응용 프로그램(Applications) 등 원하는 곳으로 옮깁니다.
2. MasterPortfolio.command 를 처음 열 때는 Control-클릭(또는 오른쪽 클릭) → [열기] → [열기]를 누릅니다.
   (서명되지 않은 프로그램이라 처음 한 번은 이렇게 열어야 합니다. 이후로는 더블클릭으로 열립니다)
   그래도 막히면 터미널에서: xattr -dr com.apple.quarantine <MasterPortfolio 폴더 경로>
3. 처음 실행하면 브라우저에 "처음 설정" 화면이 열립니다. 대학명 → 스캔할 폴더([폴더 선택]으로 고르기) → Claude 요금제·결과 폴더 → 환경 점검 순서로 진행합니다.
   설정은 나중에 화면 왼쪽 아래 [⚙ 설정]에서 바꿀 수 있습니다.
4. 브라우저 화면이 열립니다. 아래 작업 바에서 [새 자료 스캔] → [경험 묶기] 순서로 실행합니다.
5. 왼쪽 "할 일"에서 결정·질문 답변을 처리하고 [반영 실행] → [master 다시 만들기]를 누릅니다.
6. 끝낼 때는 화면의 [종료] 버튼을 누릅니다.

제거: MasterPortfolio 폴더를 휴지통으로 옮기면 됩니다. 결과 폴더(카드·master.md)는 따로 남습니다.

macOS가 폴더 접근 권한(문서·다운로드·데스크탑 등)을 물으면 [허용]을 눌러야 그 폴더를 스캔할 수 있습니다.
