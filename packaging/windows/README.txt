MasterPortfolio (Windows)
=========================

흩어진 과제·보고서·발표자료·코드에서 이력서·포트폴리오에 쓸 경험을 찾아 정리하는 프로그램입니다.
분석은 이 PC에 설치된 Claude Code(내 구독)로 하고, 자료는 내 PC 밖 다른 서버로 보내지 않습니다.
(가려진 텍스트만 내가 쓰는 Claude로 전송됩니다)

준비
- Claude Code 설치와 로그인: https://claude.com/claude-code (설치 후 터미널에서 claude 를 한 번 실행해 로그인)
- 인터넷 연결 (처음 분석할 때 연결 도구를 자동으로 받습니다)
- Node.js 설치는 필요 없습니다(프로그램에 포함).

설치 (권장)
1. 압축을 푼 폴더에서 install.cmd 를 더블클릭합니다.
2. 바탕화면·시작 메뉴에 MasterPortfolio 바로가기가 생깁니다.

설치 없이 바로 실행
- 압축을 푼 폴더에서 MasterPortfolio.cmd 를 더블클릭합니다.

사용 순서
1. 처음 실행하면 검은 창에서 대학명, 자료를 찾을 폴더, 결과 폴더를 묻습니다.
2. 브라우저 화면이 열립니다. 아래 작업 바에서 [새 자료 스캔] → [경험 묶기] 순서로 실행합니다.
3. 왼쪽 "할 일"에서 결정 대기(채택·보류·제외)와 질문 답변을 처리하고 [반영 실행]을 누릅니다.
4. [master 다시 만들기]로 결과 폴더에 master.md·master.html(이력서용 정리본)을 만듭니다.
5. 끝낼 때는 화면의 [종료] 버튼을 누르거나 검은 창을 닫습니다.

제거
- uninstall.cmd (설치 폴더 %LOCALAPPDATA%\Programs\MasterPortfolio 에 있음)를 실행합니다.
  결과 폴더(카드·master.md)는 지우지 않습니다.

Windows SmartScreen 경고가 나오면 [추가 정보] → [실행]을 누르세요(서명되지 않은 프로그램).
