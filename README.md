# MasterPortfolio

내 PC에 흩어진 과제·보고서·발표자료·코드에서 **이력서·포트폴리오에 쓸 경험을 찾아 정리**하는 프로그램입니다.
이미 구독 중인 Claude Code로 분석하고, 결과는 내 PC에 Markdown·HTML로 남습니다.

## 무엇을 해 주나

| 단계 | 하는 일 |
|---|---|
| **자료 찾기** | 고른 폴더(문서·다운로드·OneDrive·프로젝트 폴더·다른 드라이브 등)를 훑어 PDF·DOCX·PPTX·HWPX·MD·TXT를 찾습니다. 새 파일을 분석하고, 원본이 바뀐 파일은 알려 주기만 합니다(다시 분석은 다음 버전). 한글에서 내보낸 한글 PDF도 읽습니다. **HWP(.hwp)는 위치만 지원**합니다(아래 '지원 형식'). |
| **폴더 정리** | 폴더 이름과 파일 이름 예시만 보고 이력서와 무관한 폴더(강의자료·생성물·남의 코드 등)를 거릅니다. 애매한 폴더는 사용자에게 묻습니다. |
| **파일 카드** | 파일마다 요약·기간·역할·기술·정량 성과를 담은 카드를 만들고, 이력서 가치를 상·중·하로 판정합니다. |
| **경험 묶기** | 같은 프로젝트·활동에서 나온 카드(보고서·발표·코드)를 하나의 **경험 카드**로 묶고, 이력서에 필요한데 빠진 사실을 묻는 질문을 만듭니다. |
| **결정과 질의응답** | 경험마다 채택·보류·제외를 고르고(여러 개를 한 번에), 채택한 경험의 질문에만 답합니다. 기본으로 **수행 능력 점검**(직접 한 부분과 AI·강의·팀원의 도움)과 **실제 진행 시기**를 묻습니다. |
| **반영** | 답변으로 역할·기간·성과·STAR 요약·수행 방식(직접 수행·학습 후 재수행·AI 보조·AI 주도·개념 해석)을 채웁니다. |
| **Master Record** | 채택한 경험을 이력서 분류(프로젝트·연구·대회·CTF·교육·수업·동아리·스터디)별 최신순으로 모은 `master.md`·`master.html`을 만듭니다. 경험마다 **한 줄 복사**·**STAR 복사**를 할 수 있습니다. 화면에서 채택·답변·편집할 때마다 자동으로 다시 만들어집니다. |

## 지원 형식

| 형식 | 지원 |
|---|---|
| PDF · DOCX · PPTX · **HWPX** · MD · TXT | 내용까지 분석(카드·판정·경험 묶기) |
| **HWP**(옛 한글 형식 `.hwp`) | **위치만 지원.** 파일이 어디 있는지는 보고서에 남지만, 내용(제목·요약·성과 등)은 분석하지 않습니다. 한글에서 HWPX나 PDF로 저장해 두면 다음 스캔에서 분석합니다. |
| DOC · PPT(옛 Office 형식) | 위치만 지원. DOCX·PPTX·PDF로 저장하면 분석합니다. |
| 그 밖의 형식(이미지·압축 파일 등) | 개수만 셉니다. |

## 화면

MasterPortfolio는 **내 PC에서 도는 웹 앱**입니다. 실행하면 창 없이 뒤에서 서버가 돌고 브라우저에서 **http://localhost:4317**이 열립니다(그 포트를 다른 프로그램이 쓰면 4318~4327). 이 주소를 즐겨찾기해 두면 언제든 다시 열 수 있고, 이미 실행 중이면 바로가기를 다시 눌러도 새로 띄우지 않고 그 화면을 엽니다. 끌 때는 화면 아래의 [종료]를 누릅니다.

위쪽 메뉴: **홈 · 경험 · 마스터 · 도움말 · ⚙ 설정** (테마: 밝게·어둡게·시스템)

- **홈**: 포트폴리오 완성도(채택한 경험의 기간·수행 방식·STAR·키워드가 채워진 정도), 다음 할 일(결정 대기·답변 대기·반영 대기), [한 번에 정리], 분류별 경험 수, 최근 경험 카드.
- **경험**: 경험 카드 격자. 카드마다 제목·기간·수행 방식·**경험 키워드**(무엇을 했나)·**성과 키워드**(무엇을 이뤘나)·질문 수. 왼쪽에 할 일, 분류 목차, 분류별·연도별 보기, 상태·수행 방식 필터. 카드를 누르면 오른쪽 상세 창에서 결정·질문 답변·편집·근거 파일을 봅니다.
- **마스터**: 채택한 경험을 분류·최신순으로 정리한 Master Record 미리보기와 인쇄·PDF. 결과 폴더의 `master.md`·`master.html`은 채택·답변·편집할 때마다 자동으로 최신이 됩니다.
- **도움말**: 사용 순서, 지원 형식, 자주 묻는 질문, 문제 해결.
- **작업 바**(모든 화면 아래): **한 번에 정리**(스캔 → 묶기 → 반영 → 키워드 → master를 차례로, 중간에 실패·중지하면 거기서 멈춤) · 새 자료 스캔 · 경험 묶기 · 반영 실행 · 키워드 만들기 · master 다시 만들기 · 종료.
  실행 중에는 **단계·전체 진행률·남은 시간**과 **[중지]**(에이전트까지 함께 멈추고, 만든 카드는 남아 다음 실행에서 이어 함), 탭 제목에 진행률이 보이고, 끝나면 운영체제 알림과 **결과 요약**(예: `새 카드 12개 · 판정 12개`)을 보여 줍니다.
- **안내 배너**: Claude Code 로그인이 풀렸을 때(다시 확인), 스캔 중 애매했던 폴더의 범위 질문(설정에서 포함·제외로 답함), 마지막 스캔이 오래됐을 때, 새로 찾은 OneDrive·드라이브·WSL 폴더(체크해 추가하거나 다시 묻지 않기).
- **⚙ 설정**: 스캔 폴더 추가(운영체제 폴더 선택 창)·제거, Claude 요금제, 사용량 예산, 대학 검색 이름, 폴더 범위 판단 목록과 초기화, 환경 점검.
- 검색(`/`), 이동(`j`/`k`), 닫기(`Esc`), 좁은 화면 지원.
- **접속 보호**: 화면은 이 PC(127.0.0.1)에서만 열립니다. 처음 바로가기로 열 때 이 브라우저에만 접속 쿠키를 심어 두고, 데이터를 읽고 바꾸는 요청은 화면 안의 비밀 토큰으로만 받습니다. 다른 브라우저에서 주소만 입력하면 "바로가기로 열어 주세요" 안내가 나옵니다.

## 개인정보와 사용량

- **로컬 처리**: 파일 탐색·텍스트 추출·결과 저장은 모두 내 PC에서 합니다. 화면은 `127.0.0.1`에서만 열리고 실행마다 바뀌는 토큰으로 보호됩니다.
- **보내기 전에 거르고 가림**: 신분·금융 서류, 계정 비밀(복구 코드·키·비밀번호 파일)은 통째로 건너뜁니다. 나머지는 주민번호·전화번호·계좌·카드·여권번호를 가린 뒤 내 Claude에만 보냅니다. 에이전트의 파일 읽기·명령 실행 도구는 막습니다.
- **사용량 예산**: 빠른 모델(선별·추출·키워드)과 정밀 모델(판정·묶기·반영)을 나눠 쓰고, 5시간 사용량 창에서 정한 비율(기본 Pro 기준 30%, Max 요금제는 배수 환산)에 닿으면 멈춘 뒤 다음 실행에서 이어 합니다.
- **빠른 재스캔**: 폴더는 동시에 훑고(WSL·네트워크 폴더에서 특히 빠름), 크기·수정 시각이 그대로인 파일은 다시 읽지 않습니다. 단계별 소요 시간은 `.mp/logs`에 남습니다.
- **이어하기**: 카드는 만들 때마다 저장됩니다. 중간에 멈춰도 이미 만든 카드는 다시 보내지 않습니다. 다른 결과 폴더(옮긴 백업 포함)는 스캔하지 않습니다.

## 설치

[Releases](../../releases)에서 운영체제에 맞는 zip을 받으세요. Node.js는 포함돼 있어 따로 설치할 필요가 없습니다.

| 운영체제 | 실행 |
|---|---|
| Windows 10/11 (x64) | 압축 해제 → `install.cmd`(바탕화면·시작 메뉴 바로가기) 또는 `MasterPortfolio.cmd` |
| macOS (Apple Silicon·Intel) | 압축 해제 → `MasterPortfolio.command` (처음엔 Control-클릭 → 열기) |

**필요한 것**: [Claude Code](https://claude.com/claude-code) 설치와 로그인(그 PC에서 `claude`를 한 번 실행해 로그인), 인터넷 연결.

처음 실행하면 브라우저에 **처음 화면**이 열립니다: 하는 일과 개인정보·사용량 소개 → **Claude Code 준비**(설치·로그인을 자동으로 확인하고, 안 돼 있으면 운영체제별 설치 명령과 로그인 방법을 보여 줌) → 대학명 → 스캔할 폴더(문서·다운로드·바탕 화면 기본 체크, OneDrive·다른 드라이브 제안, WSL이 있으면 홈 안의 projects·portfolio 같은 폴더를 찾아 체크하고 알림, [폴더 선택]으로 추가) → Claude 요금제·결과 폴더 → 환경 점검 → **[첫 정리 시작]** 순서로 진행하고, 그다음부터는 바로 홈 화면이 열립니다. 이미 결과가 있는 폴더를 고르면 덮어쓰지 않고 그대로 이어 씁니다.

## 명령줄(CLI)

화면의 모든 작업은 명령으로도 할 수 있습니다.

```
mp start      화면 서버를 뒤에서 띄우고(이미 실행 중이면 그대로) 브라우저로 열기
mp ui         화면 서버를 이 터미널에서 실행(개발·문제 해결용, 임의 포트)
mp init       대학명·스캔 폴더·요금제·결과 폴더 설정
mp scope      폴더 범위 정리(LLM 판단 + 질문)
mp scan       새 파일을 분석 → 파일 카드 (원본이 바뀐 파일은 알려 주기만 한다. 다시 분석은 다음 버전)
mp group      파일 카드 → 경험 카드 + 질문
mp review     결정 → 질문 답변 → 반영 (--file: review.md로 답하기)
mp keywords   경험·성과 키워드
mp master     master.md·master.html
mp doctor     환경 점검
```

